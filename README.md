# Tum, já é certo — Minecraft Resource Pack

Custom sounds for mining in **Minecraft: Java Edition**.

| Moment | Sound |
|---|---|
| Mining (the repeated hit) | short "tum" ticks — `tum-1` / `tum-2`, picked at random |
| Block breaks | "tum, já é certo" |

## Requirements

- Minecraft Java Edition **1.21.8** (`pack_format 64`)
- Client-side only — works on any server

## Install

1. Download the latest `tum-ja-e-certo-*.zip` from [Releases](../../releases/latest).
2. Drop it into your `resourcepacks` folder:
   - **Linux:** `~/.minecraft/resourcepacks/`
   - **Windows:** `%appdata%\.minecraft\resourcepacks\`
   - **macOS:** `~/Library/Application Support/minecraft/resourcepacks/`
3. **Options → Resource Packs** → enable it.
4. Press `F3+T` to reload (or restart the game).

## Which blocks does it affect?

It overrides `block.stone.hit` and `block.stone.break`, which covers every block
using the **stone sound group**: stone, cobblestone, ores, bricks, and so on.
Deepslate, wood, dirt, gravel and other materials have their own sound groups and
are left untouched.

## Building from source

Requires `ffmpeg` and `zip`.

```bash
./build.sh
```

Output: `dist/tum-ja-e-certo.zip`.

The script converts the WAVs in `sounds-src/` to **mono 44.1 kHz OGG Vorbis**
(mono is required for Minecraft to position block sounds in 3D), then zips
`pack/` so that `pack.mcmeta` sits at the archive root.

## Project layout

```
sounds-src/                     original WAV files
pack/
  pack.mcmeta                   pack metadata (format 64)
  assets/minecraft/
    sounds.json                 sound event overrides
    sounds/custom/*.ogg         generated by build.sh
build.sh                        encode + zip
dist/                           built pack (not committed)
```

## Notes

- Client-side only: other players on a server still hear the vanilla sounds.
- A resource pack cannot change the mining hit interval (~0.25 s). The two hit
  variants are short enough (~0.1 s) to fit inside that gap without overlapping.
- The break sound is 1.72 s. Breaking blocks faster than that (e.g. Efficiency V)
  will restart it before it finishes, so phrases can overlap. Lower its `volume`
  in `sounds.json` if that gets annoying.
